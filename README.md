# Blue Mountains Data Audit

悉尼大学 ENGG2112「多学科工程」课程小组项目的个人数据核验案例。小组研究利用历史观测数据识别澳大利亚蓝山国家公园次日可能出现卫星火点检出的区域。我负责建模数据的交接核验，重点检查多表关联、日期对齐和标签口径。

| 原项目核验 | 结果 |
| --- | --- |
| 建模数据表 | 18,980 行，52 个网格 × 365 个特征日期 |
| 可验证检查 | 54 项通过 |
| 仍有证据缺口 | 2 项，涉及卫星观测机会和火灾缺失的独立验证 |

**标签口径**　零标签表示档案中没有符合条件的卫星火点检出。判定实际火灾是否发生，需要独立的事件记录或观测覆盖数据。

## 运行示例

下载或克隆仓库，在仓库目录使用 Python 3.10+ 运行：

```sh
python -m pip install -r requirements.txt
python audit.py
```

示例 CSV 为合成数据，包含 2 个网格和 3 个特征日期。脚本输出 JSON，包含 10 项检查的状态和月度标签汇总。检查失败时退出码为 1，文件或输入格式有误时为 2。

脚本对照建模表和参考标签表，检查网格与日期组合键、次日目标对齐、合资格检出次数及标签一致性。关联时保留建模表的全部行，因此参考表缺少标签时，缺行会出现在检查结果中。
